# Herramienta de prototipado: Emergent

---

Emergent se utilizará como herramienta para diseñar y construir el prototipo. De acuerdo con la información oficial consultada en septiembre de 2026, permite crear aplicaciones web y móviles describiendo en lenguaje natural las pantallas, funciones y flujos necesarios. La plataforma puede generar interfaz, estructura, lógica y componentes de la aplicación.

## ¿Por qué utilizar Emergent?

- Permite crear prototipos funcionales mediante instrucciones en lenguaje natural.
- Puede generar interfaces, formularios, tablas, filtros y otros componentes visuales.
- Permite trabajar con aplicaciones web y móviles.
- Las funciones pueden modificarse y refinarse posteriormente mediante nuevas instrucciones.
- Puede manejar datos y lógica de backend, útil para guardar información del viaje.
- Permite incorporar autenticación, flujos, notificaciones e integraciones conforme crezca el prototipo.

## Aplicación de Emergent en nuestro proyecto

| Función | Implementación propuesta |
|---|---|
| Alerta Schengen | Registrar fechas, calcular días consumidos/restantes y mostrar alertas. |
| Checklist de viaje | Lista interactiva de pasaporte, boleto de regreso, hospedaje y seguro opcional. |
| Conversor MXN/EUR | Ingresar un monto en MXN y obtener automáticamente su equivalente en EUR. |

## Flujo de trabajo propuesto

1. **Definir:** describir en Emergent el objetivo general de la aplicación.
2. **Generar:** solicitar las pantallas principales y las tres funciones seleccionadas.
3. **Probar:** verificar cálculos, formularios y alertas con datos de ejemplo.
4. **Refinar:** corregir diseño, textos, navegación y comportamiento mediante nuevas instrucciones.
5. **Presentar:** utilizar el prototipo funcional como demostración del proyecto.

## Alcance inicial del prototipo

La primera versión no necesita implementar todos los requerimientos. Con los puntos 2, 3 y 9 se puede demostrar un flujo coherente: el usuario revisa su situación Schengen, valida la documentación necesaria y convierte su presupuesto de pesos mexicanos a euros. Posteriormente pueden agregarse comparadores de vuelos, hospedaje, transporte, itinerarios y exportación a PDF.
